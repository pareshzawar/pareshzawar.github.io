About

Oracle Cloud Architect with 11+ years across Oracle Cloud Infrastructure, Oracle Fusion, EBS, OIC and Autonomous Database. I started as an Apps DBA and moved into cloud architecture and practice leadership.

Today I run the Oracle CloudOps practice at Automus Consulting for 15+ clients, across implementation and managed support. That covers the full OCI platform: landing zones, compute and storage, hybrid networking, databases, identity and security, observability, DevOps, FinOps and disaster recovery.

I have delivered on-prem to OCI migrations of Oracle EBS and Oracle Database, with EBS R12.2.10 and Database 19c upgrades along the way. 25 Oracle certifications since 2016.
